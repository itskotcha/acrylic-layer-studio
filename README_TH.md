# Acrylic Layer Studio

เว็บออกแบบภาพซ้อนชั้นในก้อนอะคริลิก พร้อมเครื่องมือ 2D และพรีวิว WebGL 360°

## เริ่มใช้งานบน Windows / VS Code

1. ติดตั้ง Node.js **22.12 ขึ้นไป** (รองรับ Node.js 24) พร้อม npm
2. แตก `acrylic-layer-studio-source.zip` แล้วเปิดโฟลเดอร์ `acrylic-layer-studio` ใน VS Code
3. เลือก Terminal → New Terminal และรัน:

```powershell
npm ci
npm run dev
```

4. เปิด URL ที่ Terminal แสดง โดยปกติคือ `http://localhost:5173`
5. หยุดเซิร์ฟเวอร์ด้วย Ctrl+C

ต้องใช้อินเทอร์เน็ตตอนติดตั้งแพ็กเกจครั้งแรก หลังติดตั้งแล้วตัวแอป รูปตัวอย่าง และฟอนต์ทำงานจากเครื่อง ไม่ต้องมี API key หรือเซิร์ฟเวอร์ฐานข้อมูล อย่าเปิด index.html ด้วยการดับเบิลคลิก ให้เปิดผ่าน dev server หรือ preview server

ถ้า PowerShell ไม่อนุญาต npm.ps1 ให้ใช้ `npm.cmd ci` และ `npm.cmd run dev` แทน ไม่ต้องเปลี่ยนนโยบายเครื่อง

## Build สำหรับใช้งาน

```powershell
npm run build
npm run preview
```

เปิด URL ที่แสดง โดยปกติ `http://localhost:4173` ไฟล์ build อยู่ใน `dist/` และนำไปวางบน static hosting ได้ ไม่มีการ deploy หรืออัปโหลดรูปของผู้ใช้จากแอปนี้โดยอัตโนมัติ

## ขั้นตอนใช้งาน

### 1. เลือกขนาด

เมื่อเปิดครั้งแรกจะมีสองทางเลือก:
- **ตามภาพแรก**: เลือกรูป ระบบใช้ขนาดพิกเซลและสัดส่วนตามรูปนั้น
- **เลือกสัดส่วน**: เลือก 1:1, 3:4, 4:3, 9:16, 16:9 หรือใส่ความกว้างสูงเอง ค่าปุ่มสัดส่วนเป็นค่าเริ่มต้น แก้จำนวนพิกเซลเพิ่มได้

กด “กลับไปดูงานในสตูดิโอ” เพื่อทดลองตัวอย่างที่เตรียมไว้ หรือกด “ใหม่” บนแถบด้านบนได้ทุกเวลา

### 2. นำเข้ารูปและจัดองค์ประกอบ

กด **เพิ่มรูปภาพ** เพื่อเลือก PNG/JPEG/WebP ได้หลายรูป ภาพใหม่แยกชั้นเป็นค่าเริ่มต้น หากเลือก “เพิ่มลงชั้นที่เลือก” ภาพจะอยู่ร่วมชั้นกับวัตถุเดิม

ควรมีอย่างน้อยสองภาพเพื่อเห็นมิติของภาพซ้อนชั้น แต่ระบบยอมให้บันทึกงานที่ยังทำไม่เสร็จได้

ใช้ **เลือก** เพื่อคลิกและลากวัตถุ ลากมุมเพื่อย่อ–ขยายแบบรักษาสัดส่วน ลากจุดหมุนเพื่อหมุน หรือกรอกค่าทางขวาแล้วกด Enter/ออกจากช่อง

- Fit: เห็นภาพครบ มีพื้นที่ว่างได้
- Fill: เต็มพื้นที่และครอปส่วนเกิน ไม่บีบสัดส่วน
- ภาพเกินขอบ canvas จะถูกตัดในพรีวิวและ export
- พื้นขาวในหน้า 2D เป็นพื้นช่วยมอง ไม่ถูกฝังใน PNG ส่วน alpha เดิมยังคงอยู่
- ภาพ JPG และรูปที่มีพื้นทึบจะบังชั้นหลังตามจริง ไม่มีระบบลบพื้นหลังอัตโนมัติ

### 3. เลเยอร์

รายการด้านบนคือชั้นหน้า ด้านล่างคือชั้นหลัง ใช้ปุ่มเลื่อนขึ้น/ลง ซ่อน ล็อก ทำสำเนา และลบ คลิกชื่อชั้นเพื่อเลือก จากนั้นเลือกวัตถุในรายการย่อยได้แม้ถูกวัตถุอื่นบังอยู่

หนึ่งชั้นเก็บหลายภาพ ข้อความ และเส้นวาดได้ ทุกวัตถุในชั้นใช้ความลึกเดียวกัน ย้ายวัตถุไปชั้นอื่นในแผงคุณสมบัติได้

ปุ่ม **วัตถุขึ้นหน้า / วัตถุไปหลัง** เปลี่ยนลำดับภายในชั้น ส่วนปุ่มลูกศรในแถวเลเยอร์เปลี่ยนความลึกของทั้งชั้น

### 4. วาดและพิมพ์

เลือกชั้นที่ไม่ล็อกและเปิดแสดงอยู่ แล้วใช้ปากกา ปรับสี ขนาด และความทึบก่อนลากวาด

**ลบเส้น** เป็นยางลบทั้งเส้น: แตะส่วนใดของเส้นนั้นเพื่อลบทั้ง stroke ไม่ตัดบางส่วนของเส้นและไม่ลบภาพ/ข้อความ

กดข้อความ แล้วแก้ข้อความ ฟอนต์ สี ขนาด และการจัดแนวในแผงขวา รองรับไทยด้วย Noto Sans Thai ที่รวมไว้ในแพ็กเกจ

Undo/Redo ใช้ปุ่มด้านบนหรือ Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z, Ctrl+Y หนึ่งการลากวัตถุและหนึ่งเส้นวาดเป็นหนึ่งประวัติ Ctrl/Cmd+D ทำสำเนาวัตถุ Delete/Backspace ลบวัตถุ คีย์ลัดเหล่านี้ไม่ทำงานขณะพิมพ์ในช่องข้อความ

### 5. ความหนาและระยะชั้น

ความสูงก้อนกำหนดเป็น 3 หน่วยเสมือน ความหนาปรับได้ 0.1–2 หน่วย ค่านี้ **ไม่ใช่มิลลิเมตร**

ความลึกชั้นเป็นค่า normalized: 0 = หลัง, 1 = หน้า ระบบเผื่อผิวและรักษาระยะห่างขั้นต่ำจากชั้นข้างเคียง การปรับความหนาจะรักษาสัดส่วนความลึกเดิมไว้ ปุ่มกระจายระยะเท่ากันจัดชั้นใหม่ให้มีระยะเท่ากัน

### 6. พรีวิว

เปิดแท็บ **พรีวิว 3D** แล้วลากเพื่อหมุน ใช้ wheel หรือ pinch เพื่อซูม เอียงดูด้านบน/ล่างได้

- หมุนอัตโนมัติ: เปิด/หยุด
- มุมหน้า / รีเซ็ต: สลับหน้าตรงกับมุมเฉียงเริ่มต้น
- แยกชั้น: ดูองค์ประกอบแยกชั้นชั่วคราว แล้วประกอบกลับ ข้อมูลความลึกที่บันทึกไม่เปลี่ยน
- คุณภาพสูง/ประหยัดพลังงาน: ใช้ texture สูงสุด 2048/1024 px และลด pixel ratio
- ด้านหลังเป็นภาพกลับด้านตามการมองผ่านแผ่น รูปทึบด้านหลังอาจบังภาพชั้นหน้าทั้งหมดเมื่อมองจากหลัง ซึ่งเป็นพฤติกรรมที่ตั้งใจ

### 7. บันทึกและส่งออก

**บันทึกโปรเจกต์** ดาวน์โหลด `.acrylic.zip` ที่มี `project.json` และ assets จริง เปิดต่อด้วยปุ่ม **เปิดงาน** ได้บนเครื่องอื่น ไม่ต้องใช้รูปต้นฉบับแยก

งานบันทึกอัตโนมัติใน IndexedDB ของเบราว์เซอร์เดียวกันที่ URL/origin เดิม รอข้อความ “บันทึกในเครื่องแล้ว” ก่อนปิดหน้า การล้างข้อมูลเว็บ/ใช้โหมดส่วนตัวอาจทำให้งานหาย จึงควรดาวน์โหลดโปรเจกต์เป็นระยะ

**ส่งออก**:
- PNG ภาพด้านหน้า: รวมเฉพาะชั้นที่เปิดแสดง ขนาดเต็ม canvas
- ZIP ภาพแยกทุกชั้น: ส่งออกทุกชั้นรวมชั้นที่ซ่อน ทุก PNG ขนาดเท่ากันและคง alpha
- PNG มุมสามมิติ: เปิดพรีวิว เลือกมุม แล้วกด “บันทึกภาพ 3D” ได้ภาพตามขนาด viewport รวมฉากและเงา ไม่มี UI

`acrylic-layer-studio-source.zip` คือซอร์สโค้ดแอป ส่วน `.acrylic.zip` คือผลงานที่เปิดด้วยแอป ไม่ใช่โปรเจกต์ npm

## ข้อจำกัดของรุ่นนี้

- วัสดุอะคริลิกเป็น **ผิวโปร่งใสสะท้อนแสงแบบประมาณค่า** และเงาแบบนุ่มจำลอง ไม่ใช่การจำลอง refraction/caustics ทางฟิสิกส์หรือภาพรับรองงานผลิตจริง วิธีนี้คงการเห็น texture alpha หลายชั้นจากทั้งหน้าและหลังได้เสถียรกว่าเส้นทาง transmission ปกติ
- กล้องเป็น orthographic เพื่อให้หน้าตรงตรงกับองค์ประกอบ 2D ทุกชั้น เมื่อหมุนยังเห็น parallax และความหนา
- พรีวิว 3D ลดความละเอียดเพื่อประสิทธิภาพ ส่วน PNG 2D ใช้ขนาด canvas เต็ม
- ไม่มี partial-stroke eraser, pressure-sensitive brush, AI ลบพื้นหลัง, GLB/video export, งานด้านหลังแยก, ระบบสมาชิก/คลาวด์/สั่งผลิต
- งาน 64–4096 px ต่อด้าน, ไม่เกิน 24 depth layers, 500 วัตถุ, 100 image assets ต่อเซสชัน รูปแต่ละไฟล์ไม่เกิน 20 MB และ 32 ล้านพิกเซล รูปรวมที่นำเข้าไม่เกิน 100 MB โปรเจกต์นำเข้าไม่เกิน 120 MB
- Undo เก็บ 40 ขั้นย้อนหลัง การลบรูปอาจยังเก็บ asset ไว้ในเซสชันเพื่อ Undo; บันทึกแล้วเปิดไฟล์ใหม่จะโหลดเฉพาะ asset ที่ใช้งานจริง
- ภาพแรกสำหรับโหมดตามรูปต้องมีทุกด้าน 64–4096 px รูปใหญ่กว่านี้ใช้โหมดเลือกสัดส่วนแล้วนำเข้าภายหลัง หรือย่อรูปก่อน
- ผ่าน browser tests บน Chromium แบบ headless และ viewport มือถือ ไม่ใช่การรับรองผลบนโทรศัพท์จริง/Safari/Firefox ทุกเครื่อง

## แก้ปัญหา

- รูปไม่แสดง: ตรวจชนิด ขนาด และไฟล์เสีย / ลอง PNG ใหม่
- ชั้นหลังไม่เห็น: รูปด้านหน้าอาจมีพื้นทึบ ตรวจ alpha ของ PNG
- วาดไม่ได้: เลือกชั้นที่ไม่ล็อกและเปิดแสดง จากนั้นเลือกปากกา
- 3D ไม่เปิด: เปิด hardware acceleration ในเบราว์เซอร์ หรือลอง Chrome/Edge โหมด 2D ยังบันทึกและส่งออกได้
- พรีวิวหยุดเพราะ WebGL context lost: สลับกลับ 2D แล้วเข้า 3D ใหม่ หรือลดคุณภาพ
- Autosave ล้มเหลว: ดาวน์โหลดโปรเจกต์ทันที ตรวจพื้นที่เบราว์เซอร์
- เปิดพอร์ตไม่ได้: `npm run dev -- --host 127.0.0.1 --port 5174`
- `npm ci` error: ตรวจ Node version และการเชื่อมต่อ ไม่ต้องลบ lockfile เพื่อแก้เอง

## โครงสร้างโค้ด

- `src/model.ts`: schema, ขีดจำกัด, ความลึก, validation
- `src/store.ts`: Zustand, history, mutation
- `src/io.ts`: import, archive, IndexedDB
- `src/raster.ts`: rasterize ด้วย Konva เพื่อให้ 2D/3D/export ใช้ metrics เดียวกัน
- `src/demo.ts`: สร้างภาพตัวอย่างในเครื่อง
- `src/components/Editor.tsx`: interactive canvas
- `src/components/Preview.tsx`: WebGL scene/material/camera
- `src/components/LayerList.tsx`: เลเยอร์และวัตถุ
- `src/components/Properties.tsx`: ตัวแก้คุณสมบัติ
- `src/components/NewProject.tsx`: เลือกขนาดสองวิธี
- `src/App.tsx`: การไหลงานและ autosave
- `tests/`: tests ข้อมูลและ browser
