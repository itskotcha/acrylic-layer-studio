# Acrylic Layer Studio v3

เว็บออกแบบรูป ข้อความ และเส้นวาดบนชั้นในก้อนอะคริลิก พร้อมมุมมอง 3D หมุน 360° พัฒนาต่อจากซอร์ส v2 ด้วย React, TypeScript, Konva และ Three.js ใช้ dependencies เดิม ไม่ต้องมีบัญชี backend หรือ API key

## เปิดใน VS Code

1. ติดตั้ง Node.js 22.12 ขึ้นไป (ทดสอบด้วย Node.js 24.19.0)
2. แตก `acrylic-layer-studio-v3-source.zip` แล้วเปิดโฟลเดอร์ `acrylic-layer-studio-v3` ใน VS Code
3. เลือก Terminal → New Terminal แล้วรัน:

```sh
npm ci
npm run dev
```

เปิด URL ใน Terminal โดยปกติคือ `http://localhost:5173` หยุดด้วย Ctrl+C ต้องใช้อินเทอร์เน็ตขณะติดตั้งแพ็กเกจครั้งแรก ฟอนต์ในแอปและภาพตัวอย่างเสิร์ฟจากแอปเอง

Windows: หาก PowerShell บล็อก npm.ps1 ใช้ `npm.cmd ci` และ `npm.cmd run dev` อย่าดับเบิลคลิก index.html โดยตรง

## Build และตรวจ production

```sh
npm run build
npm run preview
```

เปิด URL ที่แสดง โดยทั่วไปคือ `http://localhost:4173` นำโฟลเดอร์ `dist` ไปใช้กับ static hosting ได้ การอ่านคลิปบอร์ดต้องใช้ HTTPS หรือ localhost และขึ้นอยู่กับสิทธิ์ของเบราว์เซอร์

## เครื่องมืออยู่ที่ไหน

- **แถบบน:** ชื่อโปรเจกต์ ใหม่ เปิดงาน Undo/Redo บันทึกโปรเจกต์ ส่งออก และปุ่มเฟืองตั้งค่า
- **ด้านซ้าย:** เลือก ปากกา ยางลบ ข้อความ เลื่อนผืนงาน รูปภาพ พื้นหลัง และรายการชั้น กด “รูปภาพ” เพื่อเลือกไฟล์หรือวางจากคลิปบอร์ด และเลือกเพิ่มลงชั้นที่เลือกได้
- **ตรงกลาง:** ออกแบบ 2D / ดูแบบ 3D ด้านล่างมีซูมและปุ่ม “พอดีหน้าจอ” แยกจากตัวเลขเปอร์เซ็นต์
- **ด้านขวา:** แท็บวัตถุ / ชั้น / โปรเจกต์ เมื่อเลือกวัตถุ แสดงคุณสมบัติของวัตถุนั้นก่อน ตำแหน่ง X/Y อยู่ใน “ตำแหน่งเพิ่มเติม”
- **ฟอนต์:** เลือกฟอนต์จากช่องรายการ กด “ค้นหาและนำเข้าฟอนต์” เพื่อดูตัวอย่าง ค้นหา หรือเพิ่มไฟล์ฟอนต์
- **มือถือ:** ปุ่มด้านล่างเปิดแผงเครื่องมือหรือคุณสมบัติ ปิดด้วยปุ่มปิดหรือแตะพื้นหลังนอกแผง เมนูหมุนแสดงเหนือแถบวัตถุ
- **ตั้งค่า:** ธีมสว่าง/มืด/ตามระบบ พื้นโต๊ะทำงาน และช่วยจัดแนว การเปลี่ยนธีมไม่เปลี่ยนสีภาพหรือแสงในฉาก 3D

โหมด 3D ซ่อนเครื่องมือวาดและนำเข้าที่ไม่ได้ใช้ เพื่อเพิ่มพื้นที่ให้ตัวอย่าง รายการชั้นและแท็บชั้น/โปรเจกต์ยังปรับตำแหน่งในก้อนและความหนาได้

## หมุนวัตถุ

1. เลือกรูป ข้อความ หรือเส้นวาดจากผืนงานหรือรายการในชั้น
2. กดไอคอนหมุนที่แถบ **ล็อก / ทำซ้ำ / ลบ / หมุน**
3. ลากตัวเลื่อน 0–360° หรือกรอกองศาแล้วกด Enter/ออกจากช่อง ใช้ปุ่ม −90°, +90° หรือคืนค่า 0° ได้
4. หมุนรอบกึ่งกลางโดยรักษาขนาดและรอยลบ ลากตัวเลื่อนหนึ่งครั้งนับเป็นหนึ่ง Undo ภาพตัวอย่างขณะลากยังไม่เขียนลงโปรเจกต์จนปล่อย
5. วัตถุหรือชั้นที่ล็อกจะหมุนไม่ได้ ค่า 360° เก็บเป็น 0° เพราะเป็นมุมเดียวกัน

มีเครื่องมือหมุนชุดเดียวกันในแท็บวัตถุด้วย กด Escape หรือปุ่มปิดเพื่อปิดแผงหมุน มุมของวัตถุต่างจากการลากก้อน 3D: แบบแรกแก้งาน แบบหลังเปลี่ยนมุมกล้องเท่านั้น

## หน่วยออกแบบและความละเอียด

`100 × 100` คือสัดส่วนและพิกัดในการออกแบบ **ไม่ใช่ 100 px และไม่ใช่มิลลิเมตร** ภาพต้นฉบับเก็บแยกจากขนาดพื้นที่ เลือก 1K / 2K / 4K จากเมนูส่งออก โดยตัวเลขหมายถึงด้านยาวที่สุดของไฟล์ภาพ

| พื้นที่ออกแบบ | ส่งออก | ขนาดภาพ        |
| ------------- | ------ | -------------- |
| 100 × 100     | 2K     | 2048 × 2048 px |
| 100 × 150     | 2K     | 1365 × 2048 px |
| 75 × 100      | 4K     | 3072 × 4096 px |

ภาพ 3D ใช้สัดส่วนกรอบแสดงผลปัจจุบัน ระบบเรนเดอร์ใหม่ที่ความละเอียดส่งออกและคืนค่ากล้อง/renderer เมื่อจบ การเพิ่มพิกเซลไม่เพิ่มรายละเอียดที่ไม่มีในภาพต้นฉบับขนาดเล็ก ความหนาในฉากใช้หน่วยเสมือน ไม่ใช่ขนาดผลิตจริง

## ขั้นตอนทำงาน

1. สร้างพื้นที่ตามสัดส่วนภาพแรก หรือเลือก 1:1, 3:4 และอัตราส่วนอื่น/กำหนดเอง
2. เพิ่มรูปด้วยไฟล์ ลากวาง หรือ Ctrl/Cmd+V; ขณะพิมพ์ในช่องข้อความ การวางยังเป็นการแก้ไขข้อความตามปกติ
3. เพิ่มแผ่นพื้นหลังสีเดียว ไล่สี หรือโปร่งใส โดยใช้ขนาดพื้นที่ที่เลือก
4. จัดวางภาพด้วยเห็นภาพครบ/เต็มพื้นที่ ลาก ปรับขนาด หมุน ความทึบ 0–100% และจัดกลาง
5. วาดด้วยปากกา 6 หัว: กลม ดินสอ มาร์กเกอร์ ไฮไลต์ แอร์บรัช หัวแบน มีแผ่นทดลองก่อนวาดจริง ยางลบเลือกทั้งเส้นหรือบางส่วนได้ และไม่ลบภาพ/ข้อความ
6. เพิ่มข้อความและฟอนต์ TTF/OTF/WOFF/WOFF2 เลือกฝังฟอนต์ใน ZIP ได้ตามสิทธิ์ของฟอนต์ ถ้าขาดฟอนต์เมื่อเปิดงาน จะมีหน้าต่างให้นำเข้าหรือเลือกแทน
7. จัดชั้นจากหลังไปหน้า เปิด/ซ่อน ล็อก สำเนา เปลี่ยนลำดับ และปรับ “ตำแหน่งในก้อน” จากแท็บชั้น
8. ดูแบบ 3D ลากหมุน ซูม แยกชั้น หรือหมุนอัตโนมัติ สลับกลับ 2D แล้วมุมมองซูม/เลื่อนและกล้องยังอยู่ในตำแหน่งเดิมภายในเซสชัน การสร้างงานใหม่เริ่มมุมมองใหม่
9. บันทึกโปรเจกต์ ZIP เพื่อแก้ต่อ หรือส่งออก PNG ด้านหน้า ZIP ภาพแยกทุกชั้น และ PNG มุม 3D

Space ค้างเพื่อเลื่อนผืนงาน, Ctrl/Cmd+Z ย้อนกลับ, Ctrl/Cmd+Shift+Z หรือ Ctrl/Cmd+Y ทำซ้ำ, Ctrl/Cmd+D ทำสำเนาวัตถุ, Delete/Backspace ลบวัตถุ การพิมพ์ใน input/textarea ไม่ถูกแย่งคีย์ลัด

## เปิดงานเก่าและการบันทึก

ใช้ “เปิดงาน” เลือก `.acrylic.zip` จาก v1/v2/v3 ได้ โครงสร้างข้อมูลยังเป็น **schemaVersion 2** ไม่เพิ่มเพียงเพราะชื่อแอปเปลี่ยน ระบบแปลงพิกัดงาน v1 เป็นหน่วยออกแบบ และรักษา assets/ชั้น/ความลึก/รอยลบ/ฟอนต์ของงาน v2

ตัวอย่างใน `examples/`: `legacy-v1.acrylic.zip`, `still-here.acrylic.zip`, `brush-gallery-v2.acrylic.zip`

Autosave ใช้ IndexedDB ของเบราว์เซอร์เดิม และอ่านพื้นที่บันทึก v2 เดิมได้ ไม่ใช่การสำรองบนคลาวด์ โปรดดาวน์โหลดโปรเจกต์เมื่อเสร็จงาน การล้างข้อมูลเว็บ เปลี่ยน origin/พอร์ต หรือโหมดส่วนตัวอาจทำให้ไม่พบ autosave ประวัติ Undo จำกัด 40 ขั้นและไม่เก็บใน ZIP

## ข้อจำกัดและแก้ปัญหา

- ใช้ 3D ต้องมี WebGL/การเร่งกราฟิก หากไม่พร้อม กลับโหมด 2D เพื่อบันทึกงาน
- Clipboard ขึ้นกับเบราว์เซอร์และสิทธิ์ รวมถึงวิธีที่แอปต้นทางคัดลอกรูป หากวางไม่ได้ ให้ดาวน์โหลดรูปแล้วเลือกไฟล์
- รองรับภาพ PNG/JPEG/WebP ไม่เกิน 20 MB และ 32 ล้านพิกเซลต่อภาพ, 24 ชั้น, 500 วัตถุ, 30 ฟอนต์ต่อโปรเจกต์ ฟอนต์ไม่เกิน 10 MB ต่อไฟล์
- งานหลายภาพใหญ่ การส่งออก 4K และหลายชั้นอาจใช้หน่วยความจำมาก ลดความละเอียดหรือเลือกพรีวิว “ประหยัดพลังงาน”
- ฟอนต์นำเข้าอาจไม่มีอักษรไทย ให้เลือกฟอนต์ที่รองรับ ภาษาและ glyph ที่ขาดจะใช้ฟอนต์สำรอง
- ผิวอะคริลิกเป็นภาพจำลอง ไม่รับรองการหักเห แสง หรือสีของชิ้นงานผลิตจริง
- View state จำเฉพาะการสลับโหมดในเซสชัน ไม่รวมใน project ZIP ไม่ใช่ฟังก์ชันกู้มุมกล้องหลังปิดเบราว์เซอร์
- ทดสอบ viewport มือถือด้วย Chromium บน Linux ไม่ได้ทดสอบ iPhone/Android เครื่องจริงหรือ Safari/Firefox ดูรายละเอียดใน TEST_REPORT.md

## ทดสอบ

```sh
npm test
npx playwright install chromium
npm run test:browser -- --workers=2
```

หากมี Chromium ที่ติดตั้งไว้แล้ว กำหนด `QA_CHROMIUM_PATH` เป็น path ของ executable ก่อนรัน browser tests รายงานและภาพหน้าจอจริงอยู่ใน `TEST_REPORT.md` และ `docs/screenshots-v3/` คำสั่ง build อาจแจ้งขนาด bundle ใหญ่เนื่องจาก editor/3D engine ซึ่งแยก 3D เป็น lazy-loaded chunk แล้ว
