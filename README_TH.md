# Acrylic Layer Studio v2

เว็บออกแบบภาพ ข้อความ และเส้นวาดซ้อนตามความลึกในก้อนอะคริลิก พร้อมพรีวิว 3D หมุน 360° พัฒนาต่อจากรุ่น 1 โดยใช้ React, TypeScript, Konva และ Three.js เดิม ไม่ต้องมี backend, บัญชีผู้ใช้ หรือ API key

## เริ่มต้นใน Windows / VS Code

1. ติดตั้ง Node.js **22.12 ขึ้นไป** ใช้กับ Node.js 24 ได้
2. แตก `acrylic-layer-studio-v2-source.zip` แล้วเปิดโฟลเดอร์ `acrylic-layer-studio-v2` ใน VS Code
3. เปิด Terminal → New Terminal แล้วรัน:

```powershell
npm ci
npm run dev
```

4. เปิด URL ใน Terminal โดยปกติคือ `http://localhost:5173`
5. หยุดด้วย Ctrl+C

ถ้า PowerShell บล็อก npm.ps1 ให้ใช้ `npm.cmd ci` และ `npm.cmd run dev` แทน ไม่จำเป็นต้องเปลี่ยนนโยบายเครื่อง ต้องต่ออินเทอร์เน็ตตอนติดตั้งแพ็กเกจครั้งแรก ฟอนต์และภาพตัวอย่างจะถูกเสิร์ฟจากแอป ไม่เรียก Google Fonts ตอนใช้งาน

อย่าดับเบิลคลิก index.html โดยตรง เพราะแอปต้องทำงานผ่าน HTTP server

## Build และตรวจรุ่น production

```powershell
npm run build
npm run preview
```

เปิด URL ที่แสดง โดยทั่วไปคือ `http://localhost:4173` โฟลเดอร์ `dist` ใช้กับ static hosting ได้ หากนำขึ้นเว็บให้ใช้ HTTPS เพื่อให้การอ่านคลิปบอร์ดทำงานตามสิทธิ์ของเบราว์เซอร์ การเปิดผ่าน LAN แบบ HTTP บางเครื่องอาจไม่มีปุ่มอ่าน clipboard ที่ใช้ได้ แต่ยังเลือกไฟล์ได้

## หน่วยออกแบบไม่ใช่พิกเซล

`100 × 100` คือพื้นที่ออกแบบสัดส่วน 1:1 **ไม่ใช่ 100 px และไม่ใช่ mm** รูปต้นฉบับถูกเก็บแยก ไม่ลดเหลือขนาดหน่วยออกแบบ

| งาน             | ส่งออก | ขนาดไฟล์ภาพ    |
| --------------- | ------ | -------------- |
| 100 × 100 หน่วย | 2K     | 2048 × 2048 px |
| 100 × 150 หน่วย | 2K     | 1365 × 2048 px |
| 75 × 100 หน่วย  | 4K     | 3072 × 4096 px |

1K / 2K / 4K หมายถึงด้านยาวที่สุด 1024 / 2048 / 4096 px ด้านสั้นปัดเป็นจำนวนเต็ม เมนูส่งออกแสดงขนาดก่อนดาวน์โหลด ใช้ขนาดเดียวกันกับภาพรวมและภาพแยกชั้น ข้อความ พื้นหลัง และแปรงเรนเดอร์ใหม่ตามขนาดนั้น ภาพต้นฉบับที่เล็กยังมีรายละเอียดจำกัดแม้เลือก 4K

ภาพ 3D ใช้สัดส่วนกรอบพรีวิวปัจจุบัน แสดงขนาดจริงใต้คำแนะนำการหมุน เลือก 1K/2K/4K จากเมนูส่งออกเช่นเดียวกัน แล้วกด **บันทึกภาพ 3D** ระบบเรนเดอร์ใหม่ใน render target พร้อม texture ตามความละเอียดที่เลือก ไม่ขยาย screenshot เดิม และคืนกล้อง/คุณภาพพรีวิวเดิมเมื่อจบ

## ขั้นตอนใช้งาน

1. **สร้างงาน** — ตามสัดส่วนภาพแรก (ด้านยาว 100 หน่วย) หรือเลือก 1:1, 3:4, 4:3, 9:16, 16:9 / กำหนดหน่วยเอง
2. **เพิ่มภาพ** — เลือกไฟล์ ลากลงพื้นที่แก้ไข หรือวางจาก clipboard เลือกได้ว่าจะเพิ่มชั้นใหม่หรือเพิ่มลงชั้นที่เลือก
3. **จัดวาง** — ใช้โหมดเลือก ลาก ปรับขนาด หมุน และแก้ค่าที่คุณสมบัติ ภาพมี Fit / Fill เมนูใกล้วัตถุมีล็อก ทำสำเนา ลบ และเพิ่มเติม มือถือแสดงแถบด้านล่าง
4. **วาด** — ปากกา 6 หัว ปรับสี ขนาด ความทึบ ทดลองบนแผ่นทดลองก่อนวาดจริง แต่ละเส้นเป็นหนึ่ง Undo แปรงมี seed จึงคงรูปลักษณ์เมื่อเปิดงานกลับ
5. **ลบงานวาด** — เลือกลบทั้งเส้นหรือบางส่วน ทำงานเฉพาะเส้นที่ไม่ล็อกในชั้นที่เลือก ไม่ลบภาพ/ข้อความ/พื้นหลัง รอยลบติดตามเส้นเมื่อย้าย หมุน หรือปรับขนาด
6. **ข้อความ** — เพิ่มข้อความ ค้นหาฟอนต์ เลือก Noto Sans Thai, Sarabun, Mali, Chonburi หรือฟอนต์ระบบ และนำเข้าฟอนต์เองได้
7. **พื้นหลังชิ้นงาน** — เพิ่มแผ่นพื้นหลังที่คุณสมบัติ จะอยู่ล่างสุดตอนสร้าง เลือกสีเดียว ไล่สีสองสี หรือโปร่งใส ปรับ HEX สีตัวอย่าง ความทึบ และทิศทางได้ กดเพิ่มอีกครั้งจะเลือกแผ่นเดิม การจัดเลเยอร์ใหม่ภายหลังยังเป็นสิทธิ์ของผู้ใช้
8. **ความลึก** — เพิ่ม/ซ่อน/ล็อก/เรียง/ทำสำเนาเลเยอร์ ปรับความลึกและความหนาก้อน หรือกระจายระยะเท่ากัน
9. **ตรวจ 3D** — ลากหมุน ซูม หมุนอัตโนมัติ ดูด้านหน้า หรือแยกชั้น พรีวิวเป็นการจำลองเพื่อจัดองค์ประกอบ ไม่ใช่การจำลองแสงหรือไฟล์ผลิตจริง
10. **บันทึก** — ดาวน์โหลด `.acrylic.zip` เพื่อเปิดแก้ไขต่อ หรือส่งออก PNG ภาพรวม, ZIP ภาพแยกชั้น และ PNG มุม 3D

ภาพรวมส่งออกเฉพาะชั้นที่เปิดแสดง ส่วน ZIP แยกชั้นส่งออกทุกชั้น รวมชั้นที่ซ่อน เพื่อให้ได้ชุดไฟล์ต้นฉบับของแต่ละชั้น

## ธีมและการเลื่อนพื้นที่

เลือกสว่าง มืด หรือตามระบบในแผงเครื่องมือ ธีมจดจำในเครื่องและติดตามการเปลี่ยนของระบบเมื่อเลือกตามระบบ ไม่เปลี่ยนสีชิ้นงานหรือฉาก 3D

พื้นโต๊ะขาว/เทา/ดำ/ตารางเป็นสีช่วยมองความโปร่งใส **ไม่ติดใน PNG 2D** ส่วนแผ่นพื้นหลังที่เพิ่มเป็นวัตถุจะติดไปกับงาน ฉากและเงา 3D ติดเฉพาะภาพส่งออก 3D

- Hand หรือ Space + ลาก: เลื่อนผืนงานชั่วคราวโดยไม่วาด
- ล้อเมาส์ หรือ +/−: ซูมรอบจุดที่ชี้
- กดเปอร์เซ็นต์ซูม: พอดีหน้าจอ
- สองนิ้ว: เลื่อน/ซูม ยกเลิกเส้นที่เริ่มวาดก่อนนิ้วที่สองลง
- เปิด/ปิดดูดติดกึ่งกลางและขอบ: เส้นช่วยจัดแนวระหว่างลาก คิดระยะจากหน้าจอ ไม่ส่งออกเส้นช่วย
- มือถือ: เปิดเครื่องมือหรือคุณสมบัติจากแถบล่าง ปิดแผงเพื่อกลับมาวาด ใช้ปุ่ม Undo บนผืนงานเพื่อลบ/คืนวัตถุโดยไม่ต้องมีแป้นพิมพ์

## ฟอนต์ของฉัน

รองรับ `.ttf`, `.otf`, `.woff`, `.woff2` ไม่เกิน 10 MB/ไฟล์ เลือกน้ำหนักและรูปแบบให้ตรงกับไฟล์ก่อนนำเข้า แต่ละไฟล์มี ID ภายในของตัวเอง ไม่ชนชื่อกัน ไม่อัปโหลดไปบริการภายนอก รูปแบบตัวอักษรขึ้นกับ glyph ที่มีในไฟล์ หากไม่มีภาษาไทยหรือสัญลักษณ์นั้น เบราว์เซอร์จะใช้ fallback เฉพาะอักษรที่ขาด ไม่รับรองว่าฟอนต์นำเข้าทุกตัวรองรับทุกภาษา

ฟอนต์ที่นำเข้าถูกเก็บกับ autosave เสมอ ส่วนการดาวน์โหลดโปรเจกต์เลือก **ฝังฟอนต์ในโปรเจกต์ ZIP** ได้ที่เมนูส่งออก ใช้เฉพาะฟอนต์ที่มีสิทธิ์ฝังและแจกจ่าย หากไม่ฝัง เมื่อเปิดงานจะมีหน้าต่างให้นำเข้าฟอนต์เดิมหรือเลือกฟอนต์แทนก่อนแทนที่งานปัจจุบัน ไม่เปลี่ยนชื่อฟอนต์เงียบ ๆ ฟอนต์ระบบ `serif` / `sans-serif` อาจหน้าตาต่างกันระหว่างระบบปฏิบัติการ

ไฟล์ฟอนต์เสียจะแจ้งข้อผิดพลาดก่อนเพิ่ม ฟอนต์ในแอปทั้งสี่ตระกูลแนบใบอนุญาตไว้ที่ `licenses/`

## Clipboard

- Desktop: Ctrl+V / Cmd+V เมื่อโฟกัสอยู่ในพื้นที่แก้ไข
- Mobile/desktop: ปุ่ม **วางจากคลิปบอร์ด** จะอ่านเฉพาะหลังผู้ใช้กด
- ต้องเป็นข้อมูลภาพจริง หากเป็น URL อย่างเดียวแอปจะแจ้งให้คัดลอกรูปภาพหรือใช้ไฟล์
- ไม่รบกวนการวางข้อความใน input / textarea
- Browser อาจไม่รองรับ หรือปฏิเสธสิทธิ์ได้ ใช้ปุ่มเพิ่มรูปภาพหรือลากไฟล์แทน ไม่มี proxy ดึงรูปข้ามข้อจำกัดของเว็บ

## เปิดงานรุ่น 1

กดเปิดงาน เลือก `.acrylic.zip` เดิม ระบบตรวจไฟล์และแปลง schema 1 → 2 อัตโนมัติ โดยให้ด้านยาว 100 หน่วย แปลงพิกัด ขนาดข้อความและเส้นในอัตราเดียวกัน คงความหนา ความลึก ลำดับชั้นและข้อมูลภาพต้นฉบับ ไม่แก้ไข ZIP เดิม การเปิดตัวอย่าง `examples/legacy-v1.acrylic.zip` ใช้ตรวจ migration ได้

Autosave อ่านข้อมูล v2 ก่อน หากไม่มีจึงลองข้อมูล v1 บน origin เดิม และบันทึกใหม่ในคีย์ v2 โดยไม่เขียนทับคีย์ v1 การเปิดคนละพอร์ต โดเมน หรือ browser profile จะเป็นพื้นที่บันทึกคนละชุด ดาวน์โหลดโปรเจกต์เป็นสำเนาสำรองก่อนล้างข้อมูลเบราว์เซอร์

## ตัวอย่างและโครงสร้าง

- `examples/legacy-v1.acrylic.zip` — งานเก่าต้นฉบับสำหรับ migration
- `examples/still-here.acrylic.zip` — ตัวอย่างเดิม เปิดด้วย migration เช่นเดียวกัน
- `examples/brush-gallery-v2.acrylic.zip` — พื้นหลังไล่สี ปากกา 6 หัว ฟอนต์ไทย 4 ตระกูล และความลึก 3 ชั้น
- `docs/` — ภาพหน้าจอจากการทดสอบจริง
- `src/model.ts`, `migrate.ts`, `store.ts` — schema, migration, history
- `src/brushes.ts`, `rendering.ts`, `raster.ts` — shared rendering และ export
- `src/fonts.ts`, `io.ts` — ฟอนต์ ZIP และ IndexedDB
- `src/components/Editor.tsx`, `Preview.tsx` — editor และ 3D
- `tests/` — unit tests และ browser integration tests

## ข้อจำกัดและแก้ปัญหา

- สูงสุด 24 เลเยอร์, 500 วัตถุ, 100 ภาพต่อเซสชัน, 30 ฟอนต์ และ history 40 ขั้น ภาพ PNG/JPEG/WebP ไม่เกิน 20 MB และ 32 ล้านพิกเซล/ไฟล์; ภาพนำเข้ารวมประมาณ 100 MB
- หน่วยออกแบบแต่ละด้าน 1–10000 ความหนาก้อนเป็นหน่วยเสมือน ไม่ใช่มิติสำหรับโรงงาน
- การส่งออก 4K หลายชั้นใช้หน่วยความจำสูง ถ้ามือถือช้าหรือ WebGL ไม่พร้อม ให้ลดเป็น 1K/2K หรือใช้คอมพิวเตอร์
- พรีวิวประหยัดพลังงานใช้ texture 1K; คุณภาพสูงใช้ 2K การส่งออกไม่ถูกจำกัดด้วยคุณภาพพรีวิว
- ไม่มีระบบสมาชิก cloud sync สั่งผลิต AI ลบพื้นหลัง GLB/video export หรือแรงกดปากกา
- แปรงเก็บ geometry และ rasterize ตามขนาดใช้งาน แต่จำกัด bitmap แปรงด้านยาว 4096 เพื่อคุมทรัพยากร วัตถุที่ใหญ่เกินผืนงานมากอาจมีรายละเอียดลดลง
- ถ้า autosave เต็ม/ถูกบล็อก จะมีข้อความให้ดาวน์โหลดโปรเจกต์ อย่าพึ่ง autosave เป็นสำเนาเดียว
- ถ้าพรีวิว WebGL หยุด ให้กลับ 2D แล้วเปิด 3D ใหม่ งานยังอยู่ใน editor
- ถ้ารันไม่ได้ ให้ใช้ `npm ci` และ Node ตามรุ่นข้างต้น หลีกเลี่ยง `npm update` เพราะอาจเปลี่ยนชุดเวอร์ชันที่ทดสอบแล้ว
